# NexaForge Labs V2

An editorial product studio website built with Next.js, Motion and Phosphor Icons.

The homepage is organized around a live idea-to-architecture interaction. Visitors can type a product idea and see its first system shape assemble in real time.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build a static export and publish it to GitHub Pages at `https://prathmesh333.github.io/NexaForge2/`.
